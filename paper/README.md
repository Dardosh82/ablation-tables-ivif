# Paper source

The LaTeX source of the paper, with its bibliography and figures. **`paper.tex` is generated — never edit it.** It is built from the Markdown drafts of the paper by `build_paper.py`, which also writes the anonymised journal manuscript.

| File | |
|---|---|
| `paper.tex` | the paper, with the author block; generated. Self-contained: the layout is inlined, so it needs no `.sty` |
| `refs.bib` | the 44 references, with DOIs where the venue issues them |
| `figures/` | the six figures, generated by `make_paper_figures.py` from the results |
| `check_paper.py` | structural checks: environments, table columns, every citation and reference resolving, every figure present, every table captioned and cited, the abstract within 250 words |

## Compiling

Compile `paper.tex` with pdfLaTeX (for example on Overleaf) or XeLaTeX, with `refs.bib` and the `figures/` folder beside it. Keep `figures/` as a folder. Every package used ships with standard TeX distributions.

```
python check_paper.py      # exit 1 on any FAIL
```
